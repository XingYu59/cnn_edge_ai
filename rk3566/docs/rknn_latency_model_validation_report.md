## 2. Existing Benchmark Dataset

字段: `npu_latency_us` (eval_perf 纯 NPU 计算时间) 用于建模; `mean_latency_us` (端到端含传输) 不用于结构预测。

## 3. Baseline Model (M1)

T = 7.394 × Total_MACs + 373.8

- Train: R²=0.550 MAE=409.6us MAPE=27.0%

- Validation: R²=0.104 MAE=559.4us MAPE=33.1%

## 4. Improved Model (M2)

T = 3.023 × Conv_MACs + 980.480 × Linear_MACs + 32.0

- Train: R²=0.987 MAE=79.8us MAPE=7.3%

- Validation: R²=0.972 MAE=112.8us MAPE=9.2%

- 聚合数据: `results/operator_database.csv` (aggregate 粒度, 无逐层伪造)
- FLOAT16 GEMM 仅在 flatten≥32768 时出现
- conv 单位开销 ~3us/M, GEMM 单位开销 ~980us/M (约 324 倍差距)

## 10. Final Latency Model

**M2 泛化良好 (val MAPE < 10%) → 保留 M2 作为主模型, 进入 Hardware-aware Model Search**

## 11. Limitations

- validation 模型数有限 (12), 结构覆盖仍非完整空间
- 随机权重模型不反映精度
- perf_debug 逐层数据为相对参考 (会降低性能)
- 未覆盖更大输入/更复杂算子/不同 batch

## 12. Next Step

- 用验证后的 M2 做 Hardware-aware Search: 以 T≈3.02·Conv+980·Lin+32 预筛候选, 配合精度/参数量做 Pareto 选优
