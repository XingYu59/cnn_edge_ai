## 4. Findings

- 总 MACs 与 latency 的 Pearson 相关性: +0.741 (当前实验数据)
- 区分 Conv/GEMM 后回归 R²: 0.550 → 0.987
- Flatten 维度与 GEMM latency 的关系见 Fig5
- 具体结论以实验组内对比为准 (A/B/C/D 组分别分析)

## 5. Limitations

- 样本量有限, 相关性/回归结果为探索性
- perf_debug 模式会降低性能, 逐层数据用于相对分析
- 随机权重模型 (A/B/C/D 组) 的 latency 与权重值无关, 仅反映结构性能
- 未覆盖更深/更宽/不同池化策略的完整空间
